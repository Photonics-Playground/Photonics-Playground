Put these six files here (download from https://gwfh.mranftl.com, charset "latin", format woff2):

instrument-sans-400.woff2   instrument-sans-500.woff2   instrument-sans-600.woff2   instrument-sans-700.woff2
ibm-plex-mono-400.woff2     ibm-plex-mono-500.woff2

Then run `python3 build.py`. Without them the site uses the device's system fonts.
